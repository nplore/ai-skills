# DocLens（文档透镜）
通用文档深度分析工具：透过文档看本质，支持深度问答与影响分析、文档版本自检，适配任意领域专业文档。

> 版本：2.2.0
> 核心理念：工作流驱动、阶段化推进、结论有据、不猜测不发散

## 核心功能
DocLens 提供两种标准化工作模式，覆盖文档分析核心场景：

### 模式1：深度问答与影响分析
上传文档并提出变更/分析类问题（如字段变更影响、规则关联分析等），工具按5阶段标准化流程逐步分析：
- 前置信息确认 → 全文档解析与相关性判定 → 变更定位 → 影响分析 → 结论汇总
- 每阶段需您确认后推进，确保分析精准；
- 所有结论均引用文档原文（标注章节标题），不猜测、不发散。

### 模式2：文档版本自检
上传文档的新旧版本，工具自动完成全维度审查：
- 版本差异提取（内容/表格/结构变更）；
- 三类问题检测：错别字/格式问题、逻辑冲突、逻辑缺陷；
- 问题分级标注：🔴 阻断级 / 🟡 风险级 / 🟢 建议级；
- 多轮确认后生成标准化审查报告。

## 快速上手
### 基础流程
1. 上传文档（支持多格式）→ 2. 选择分析模式/描述需求 → 3. 确认各阶段分析结果 → 4. 回复「生成报告」获取最终文档

### 典型场景
- 场景1：分析业务规则文档中「字段修改」的上下游影响，输出有据可查的影响清单；
- 场景2：对比新旧版产品手册，自动检测逻辑冲突、错别字等质量问题；
- 场景3：审查跨领域文档（财务/法务/IT），识别跨专业术语冲突和关联关系。

## 核心特性
✅ **结论有据**：所有分析结论均引用文档原文，标注章节标题，拒绝无依据推测；
✅ **多格式兼容**：支持 Word(.docx)、PDF、Excel(.xlsx)、Markdown(.md) 等主流格式；
✅ **阶段化推进**：每步分析结果需您确认后推进，避免遗漏关键信息；
✅ **领域无关**：适配财务、法务、IT、业务等任意领域的专业文档；
✅ **标准化输出**：最终生成结构化 Markdown 报告，可直接保存/编辑/分享；
✅ **本地知识库**：自动存储您确认的信息，后续分析可复用，无需重复确认。

## 支持的文档格式
- 文本类：`.docx` (Word)、`.pdf`、`.md` (Markdown)
- 表格类：`.xlsx` (Excel)

## 交互说明
- 首次使用：自动展示模式引导语，清晰说明两种分析模式的使用方式；
- 模式切换：支持对话中切换分析模式，保留已解析的文档信息；
- 报告生成：仅在您明确回复「生成报告」或「分析完成」时，输出最终报告。
