# DocLens（文档透镜）
通用文档深度分析工具：透过文档看本质，支持深度问答与影响分析、文档版本自检，适配任意领域的专业文档。

## 核心特性
- 📊 双模式分析：深度问答与影响分析、文档版本自检
- 📝 结论有据：所有分析结论均标注文档原文依据，拒绝无根据推断
- 📋 阶段化工作流：严格按阶段推进，每步确认再执行，避免遗漏
- 🔍 全维度审查：覆盖内容差异、逻辑冲突、格式问题、隐性缺陷
- 📄 多格式支持：解析 Word(.docx)、PDF、Excel(.xlsx)、Markdown(.md)
- 💾 知识沉淀：支持本地知识库持久化，复用历史分析结论

## 快速开始
### 1. 触发方式
上传目标文档（单份/多份/新旧版本），并输入触发关键词：
- 深度问答/影响分析：文档分析、变更影响、关联分析、深度分析
- 版本自检/对比：版本对比、版本审查、文档自检、逻辑审查

### 2. 使用流程
#### 模式1：深度问答与影响分析
1. 阶段1：确认变更对象、文档关系等前置信息
2. 阶段2：查看完整影响分析结果，确认疑问
3. 阶段3：获取最终结论，可选生成报告/沉淀知识

#### 模式2：文档版本自检
1. 上传原版+新版文档
2. 查看版本差异清单+分级问题列表
3. 确认问题后，可选生成版本审查报告

## 输出说明
- 分析过程：分阶段输出结构化结论，标注原文依据
- 最终报告：仅在明确要求时生成 Markdown 格式报告，无「待确认」模糊表述
- 知识库：沉淀内容存储至 `.doclens/knowledge/` 目录，后续分析自动复用

## 支持格式
- 文档类型：.docx、.pdf、.xlsx、.md
- 语言：中文(zh-CN)、英文(en-US)
- 输出格式：Markdown（报告可直接导入飞书/文档工具）

## 核心约束
- 结论闭环：所有口头确认需书面复述，未确认信息不纳入分析
- 一次性提问：每个阶段的疑问集中抛出，不分批咨询
- 阶段锁：未完成当前阶段确认，禁止推进下一阶段
